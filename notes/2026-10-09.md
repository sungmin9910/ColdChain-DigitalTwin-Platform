### 4. 🚀 ESP32-C6 펌웨어 5대 핵심 취약점 개선 (`carrier_board_mqtt.cpp`)

* **수정 파일**:
  * [`carrier_board_mqtt.cpp`](file:///c:/Users/yuyub/Desktop/hsm/ColdChain-DigitalTwin-Platform/Hardware_Prototypes/code26/test/src/carrier_board_mqtt.cpp)
* **5대 최적화 내역**:
  1. **GPS UART RX 버퍼 확장**:
     * 기본 128B에서 **1024B (`Serial1.setRxBufferSize(1024)`)**로 증설하여 9600bps NMEA 문장 버퍼 오버플로우 및 문장 잘림(Checksum fail) 해결.
  2. **Wi-Fi 동기 스캔 주기 완화 (블로킹 제거)**:
     * 주행 중 Wi-Fi 단절 시 매 6초마다 동기 채널 스캔(약 2.5~3.5초 CPU 독점)이 발생하여 20ms IMU 주기(50Hz)가 기아 상태에 빠지고 텔레메트리 주기가 10초로 밀리던 현상 해결.
     * 주행 중(`lastSpeedKmh >= 5.0`)에는 스캔 간격을 **20초**로 늘려 센싱 및 제어 루프의 실시간성 완벽 보장.
  3. **LittleFS 플래시 버퍼 용량 5배 증설**:
     * 300KB(약 1.5시간)에서 **1.5MB(최대 8시간 이상 연속 저장)**로 대폭 증설하여 장시간 통신 음영 및 장거리 운송 대응력 확보.
  4. **신호 대기 오판 방지 (정차 타임아웃 완화)**:
     * 도심 정체나 긴 신호 대기에서 세션이 조기 종료되는 것을 막기 위해 정차 판정 시간을 3분에서 **5분(10km/h 미만 & 60개 연속 패킷)**으로 안정화.
  5. **Wi-Fi 설정 갱신 및 안전 플러시 적용**:
     * 한글 SSID 호환성 문제를 방지하기 위해 자택 Wi-Fi를 `smroom`으로 영문 갱신.
     * `flushOfflineBuffer()` 진입 시 빈 파일인 경우 즉시 리턴하는 안전 가드 적용.

### 6. 🌐 콜드체인 MQTT 통신 구조 및 브로커 대안 심층 분석

#### 6.1. MQTT 프로토콜 사용 이유와 미사용 시 문제점
* **콜드체인 환경에서의 MQTT 필요성**:
  * **초경량 헤더 (2 Byte)**: HTTP(약 1KB 헤더) 대비 네트워크 오버헤드가 극히 적어 모바일 핫스팟/LTE 배터리 및 데이터 소모 최소화.
  * **Keep-Alive & 경량 연결 유지**: 터널이나 음영지역 진입으로 통신이 끊겨도 브로커가 상태를 감지하며, 재접속 시 즉시 복구.
  * **1:N 발행-구독(Pub/Sub) 아키텍처**: 센서 노드가 단 한 번 전송하면 Streamlit PC 대시보드, 젯슨 HUD, DB 로거가 동시에 수신 가능.
* **미사용 시 (HTTP REST / TCP 직접 통신) 발생하는 한계**:
  * HTTP 폴링/요청 방식은 연결 핸드셰이크가 매번 발생하여 CPU 전력 소모가 극심하고 패킷 낭비 발생.
  * 공인 IP가 없는 이동체(ESP32, 젯슨)에 외부 서버가 직접 데이터를 밀어넣을 수 없음.

#### 6.2. 기존 공용 브로커(`broker.emqx.io`) vs AWS EC2 Mosquitto 비교

| 비교 항목 | 기존 공용 브로커 (`broker.emqx.io`) | 자체 구축 (`AWS EC2 Mosquitto`) |
| :--- | :--- | :--- |
| **운영 주체** | EMQ 사 공개 샌드박스 (누구나 접근) | 사용자 개인 전용 클라우드 인스턴스 |
| **보안/격리** | ❌ 토픽 암호화 없음, 누구나 도청/간섭 가능 | ✅ 사용자 ID/PW, TLS/SSL, 방화벽(보안그룹) 적용 |
| **안정성 (SLA)** | ⚠️ 무료 테스트용으로 잦은 지연 및 재부팅 | ✅ 99.99% 가용성 보장, 단독 자원 점유 |
| **네트워크 트래픽** | 글로벌 서버 경유로 지연(Latency) 변동 | 국내(ap-northeast-2 서울 리전) 10ms 이내 초고속 |
| **비용** | 0원 (평생 무료 테스트용) | **AWS 프리티어 12개월 무료** (이후 월 약 5,000원) |

#### 6.3. 추천 대체 방안 3종 비교

1. **HiveMQ Cloud Serverless (강력 추천 - 설치/서버 관리 불필요)**:
   * **특징**: 웹 클릭 몇 번으로 1분 만에 생성되는 완전 관리형 브로커.
   * **비용**: **평생 무료 (디바이스 100대, 10GB/월 무료 제공)**.
   * **장점**: EC2 리눅스 설정, 방화벽 오픈, Mosquitto 유지보수 없이 안전한 전용 클라우드 브로커 구축 가능.
2. **차량 내 젯슨(Jetson) 로컬 Mosquitto 브로커 (오프라인 실시간 HUD 최적)**:
   * **특징**: 차량에 탑재된 젯슨 오린 나노에 `mosquitto`를 설치하여 핫스팟 로컬 IP로 ESP32와 직결 통신.
   * **비용**: **완전 무료 (추가 비용 0원)**.
   * **장점**: 스마트폰 LTE 데이터가 완전히 끊기거나 산간 음영지역에 있어도 차량 HUD에 속도, 온도, 진동이 1ms 지연으로 실시간 표출됨.
3. **AWS EC2 Mosquitto (독립 서버 구축)**:
   * **특징**: AWS EC2 `t4g.micro` 또는 `t3.micro` 우분투 인스턴스에 Mosquitto 직접 구축.
   * **비용**: 신규 계정 1년 무료 (프리티어 종료 후 월 약 4~6달러, 라이트세일 기준 월 3.5달러).
   * **장점**: 모든 포트, 인증, 로깅, 플러그인에 대한 100% 완전한 제어 권한 보유.
