## 📌 오늘 주요 작업 요약

오늘 작업은 **CarrierBoard 하드웨어 독립 전원(18650 배터리/스위치) 조립 및 전기적 무결성 검증**, **다중 복합 이상 이벤트(충격/조도/온도) 실시간 감지 및 즉시 DB 저장 파이프라인 구축**, **GPS Fix 기반 스마트 자동 DB 저장 모드 도입**, 그리고 **ESP32-C6 LittleFS 플래시 블랙박스 관리 유틸리티 개발 및 공식 가이드 문서화**로 구성되었습니다.

### 1. 🔋 하드웨어 전원부 결선 및 멀티미터 정밀 진단
* **18650 리튬이온 배터리(2,200mAh) 및 슬라이드 스위치(SW1) 결선**:
  * 배터리 리드선 인출형 18650 셀(실측 4.0V)을 기판 관통 홀(`BAT+`, `GND`)에 납땜.
* **스위치 3번 핀 패드 박리(Lifted Pad) 회로 분석 및 복구**:
  * 스위치 고정 중 3번 핀 패드가 탈락되었으나, KiCad 회로 분석 결과 `Net 0`(더미 NC 패드)임을 확인하여 1번(`BAT+`), 2번(`BAT`)만으로 정상 결선 완료 후 글루건으로 기계적 지지력 보강.
* **멀티미터 6단계 전원 계통 전수 진단**:
  * 배터리(4.0V) ➔ 스위치 인입(4.0V) ➔ 스위치 ON 도통(4.0V) ➔ Beetle BAT 입력(4.0V) ➔ GND 폐루프(4.0V) ➔ LDO 3.3V 정전압 출력(3.3V) 전 구간 이상 없음 확인.
  * 외부 전원(USB) 없이 배터리만으로 MCU 및 센서 4종(MPU6050, GPS, BH1750, SHT45) 완전 자립 가동 성공.

### 2. 🚨 다중 복합 이상 이벤트 감지 파이프라인 (`Step4_Run_Coldchain_v2.py`)
* **3대 핵심 파라미터 변화량(Delta) 실시간 판정**:
  1. **물리적 충격**: $g\_force \ge 1.8\text{ G}$
  2. **조도 급변**: $|\Delta\text{Lux}| \ge 300\text{ lx}$ (탑차 도어 개방 / 직사광선 유입 감지)
  3. **온도 급변**: $|\Delta\text{Temp}| \ge 2.0^\circ\text{C}$ (냉각기 고장 / 외부 열기 유입 감지)
* **동시 발생 결합 (Multi-Event Combination)**:
  * 2개 이상 동시 발생 시 `🚨 충격(2.10G) | 💡 조도급변(+520lx)` 형태로 조합하여 상태 및 지도 마커에 동기화.
* **이상 징후 즉시 DB 저장 트리거**:
  * 평상시 10초 주기를 기다리지 않고, 복합 이상 징후 발생 즉시 AWS RDS MySQL에 긴급 적재.

### 3. 🤖 GPS Fix 기반 스마트 자동 DB 저장 (Smart Auto-Save)
* **도입 배경**:
  * 연구실 실내에서 센서 작동 시험(충격/조도/온도) 시 DB 오염을 방지하면서도, 야외/차량으로 나갈 때 사용자가 수동 조작하지 않아도 되도록 개선.
* **스마트 자동 판정 알고리즘**:
  * 위성 신호 수신(`lat != 0.0 and lng != 0.0`) 여부를 자동 감지.
  * 실내(GPS 미수신): 모니터링만 수행 (DB 적재 차단).
  * 야외/차량(GPS Fix): 자동으로 DB 실시간 저장 활성화.
* **사이드바 UI 3단계 옵션 지원**:
  * `🤖 스마트 자동 (기본값)`, `🔴 항상 저장 (수동 강제)`, `⚪ 저장 안함 (연구실 모드)`.

### 4. 🛠️ LittleFS 플래시 블랙박스 원클릭 관리 도구 (`scratch/manage_littlefs.py`)
* **대화형 시리얼 CLI 유틸리티 구현**:
  * `python scratch/manage_littlefs.py` 실행으로 COM 포트 자동 탐색 및 대화형 메뉴 제공.
  * **[1] 상태 확인 (`info`)**: LittleFS 전체 용량(약 1.4MB), 사용량, 누적 패킷 수 확인.
  * **[2] 0건 완전 비우기 (`clear`)**: 주행 출발 전 기존 블랙박스 파일 및 오프라인 버퍼 영구 삭제 후 0건 초기화.
  * **[3] 데이터 백업 (`dump`)**: 보드 플래시 내부 데이터를 PC의 JSONL 파일로 고속 백업.
* **오프라인 버퍼 자동 소멸 안전장치 정립**:
  * 통신 두절 시 `/offline_buf.jsonl`에 임시 큐잉 후, 재연결 시 브로커로 플러시하고 자체 자동 삭제(`remove`)하도록 안전 로직 정립.
