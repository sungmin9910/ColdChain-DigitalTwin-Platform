> **문서 버전**: v1.0 (2026-10-07)  
> **적용 장비**: NVIDIA Jetson Orin Nano (Ubuntu 22.04 LTS, GDM3/GNOME)  
> **대상 소스**: `Final_Experiment/4_APC_Coldchain_Dashboard/Step4_Jetson_SplitHUD.py`, `scripts/`

## 📌 1. 개발 배경 및 목적

운송 차량 내부의 7~10인치 소형 모니터(또는 터치스크린) 환경에서는 기존의 PC용 복합 대시보드(`Step4_Run_Coldchain_v2.py`)를 띄울 경우 상하 스크롤이 발생하고 버튼/글씨가 작아 주행 중 시인성과 터치 조작성이 저하되는 한계가 있었습니다.

이를 극복하기 위해 **소형 화면 No-Scroll 고대비 UI**와 **운전자 맞춤 2-슬롯 동적 분할 뷰**, 그리고 **부팅 시 완전 무인 자동 켜기(Autostart) 시스템**을 구축했습니다.

## 🌟 2. 젯슨 전용 스플릿 HUD (`Step4_Jetson_SplitHUD.py`) 핵심 사양

```
┌────────────────────────────────────────────────────────────────────────┐
│ [ 🚗 [10-02 편도출발] 전주 ➔ 대전 (89km, 1,356건) ▼ ] │ 📁과거기록(1,356건) | 📡실시간: 18.2°C·0.98G·45km/h │
├────────────────────────────────────────────────────────────────────────┤
│  [1번 📍 지도]     [2번 💥 충격·속도]     [🌡️ 온·습도]     [💡 조도]   │
├───────────────────────────────────┬────────────────────────────────────┤
│                                   │                                    │
│   (선택된 과거 세션 궤적 지도)      │   (선택된 과거 세션 충격량 그래프)    │
│                                   │                                    │
└───────────────────────────────────┴────────────────────────────────────┘
```

### 2.1 주요 기능 및 사용자 경험(UX)
1. **지능형 세션 선택 드롭다운 (Session Dropdown)**
   * `🟢 실시간 주행 (현재 센서 스트리밍)`: 실시간 MQTT 패킷(`carrier-c6-01`)을 1초 주기로 스트리밍 및 동적 렌더링.
   * `🚗 [10-02 편도출발] 전주 ➔ 대전 (89km, 1,356건)`: 과거 고속도로 주행 궤적, 1.8G 이상 충격 발생 지점, 온습도 곡선 즉시 열람.
   * `🚗 [10-02 편도복귀] 대전 ➔ 전주 (85km, 478건)`, `📦 [07-15 모의주행]`, `❄️ 급랭 실험` 등 RDS 데이터 전체 자동 매핑.

2. **상시 실시간 센서 모니터링 (Dual-Tracking Pill)**
   * 과거 세션을 선택하여 지난 실험 궤적을 확인하고 있는 동안에도, 우측 상태 배지에 **`📡 실시간: 18.2°C · 0.98G · 45km/h`** 형태로 현재 차량 센서의 물리적 상태가 계속 갱신됩니다.
   * 과거 기록을 조회하는 중에도 백그라운드 MQTT 수신 큐(`data_history`)가 동작하여 실시간 데이터 유실을 100% 방지합니다.

3. **2-슬롯 동적 화면 분할 (100% 와이드 ➔ 50:50 분할)**
   * 화면 상단 4대 모듈 버튼: `[📍 지도]`, `[💥 충격·속도]`, `[🌡️ 온·습도]`, `[💡 조도]`
   * **1개 선택 시**: 전체화면 100% 너비 (높이 520px)
   * **2개 선택 시**: 좌우 50:50 분할 너비 (높이 450px)
   * **3번째 버튼 터치 시**: FIFO(선입선출) 슬라이딩 방식으로 가장 오래된 슬롯이 새 모듈로 자연스럽게 교체됩니다.

4. **차량용 No-Scroll 다크 테마**
   * 배경 `#0b0f19`, 카드 `#111827`, 여백 최소화 패딩 적용으로 1024x600 ~ 1920x1080 해상도에서 스크롤바가 전혀 생기지 않습니다.

## 🚀 3. 부팅 시 자동 실행(Autostart) 및 바탕화면 런처 구조

사용자가 젯슨 부팅 시마다 매번 터미널을 열고 명령어를 입력할 필요가 없도록 전용 자동화 스크립트군을 구축했습니다.

### 3.1 파일 구성 (`scripts/`)
| 파일명 | 기능 및 역할 |
| :--- | :--- |
| **`install_jetson_autostart.sh`** | 젯슨 바탕화면 바로가기 아이콘 생성 + 부팅 시 Autostart 자동 등록 + 즉시 화면 런처 실행 통합 인스톨러 |
| **`run_jetson_hud.sh`** | 이전 프로세스 정리 ➔ Streamlit 백그라운드 기동 ➔ 8501 포트 curl 대기 ➔ Epiphany 브라우저 자동 오픈 원클릭 런처 |
| **`stop_jetson_hud.sh`** | Streamlit 백그라운드 프로세스 및 Epiphany 브라우저 안전 종료 |
| **`uninstall_jetson_autostart.sh`** | 바탕화면 아이콘 및 자동 실행 설정 완전 삭제/복구 |

### 3.2 젯슨 터미널 1회 설치 명령
```bash
cd ~/ColdChain-DigitalTwin-Platform
git pull origin main
bash scripts/install_jetson_autostart.sh
```

### 3.3 설치 후 동작 방식
1. **바탕화면 아이콘**:
   * `[ColdChain HUD 실행]`: 더블클릭/터치 시 즉시 대시보드 가동.
   * `[ColdChain HUD 종료]`: 더블클릭/터치 시 즉시 대시보드 및 브라우저 종료.
2. **부팅 자동 실행**:
   * 젯슨 전원 인가 ➔ 부팅 후 로그인 시 4초 후 자동으로 대시보드 브라우저 화면이 전체 화면으로 열립니다.
3. **차량용 완전 무인 부팅 (추천)**:
   * 젯슨 화면의 `Settings(설정)` ➔ `Users(사용자)` ➔ `Automatic Login(자동 로그인)`을 **ON**으로 활성화하면, 비밀번호 입력 없이 전원만 켜도 바로 대시보드가 열립니다.

## 🛠️ 4. 트러블슈팅 및 팁

1. **브라우저 드라이버 안내 메시지 (`libEGL warning: ...`)**:
   * Epiphany 브라우저가 Tegra GPU 가속 경로 대신 표준 소프트웨어 렌더링(Mesa)으로 안전 전환되었다는 리눅스 정상 로그이며, 기능 동작에는 영향이 없습니다.
2. **수동 종료 및 재시작**:
   * 종료: `bash scripts/stop_jetson_hud.sh`
   * 재시작: `bash scripts/run_jetson_hud.sh`
