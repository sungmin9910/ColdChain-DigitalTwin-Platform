# v18 Apple Sensor Pod (사과 모형 3D 프린터 하우징)

본 프로젝트는 스마트 콜드체인(저온 유통) 디지털 트윈 모니터링을 위해 설계된 **실물 과일 형상(Apple Dummy Sensor Node) 3D 프린팅 하우징**입니다.  
사용자가 제시한 단면 설계 컨셉을 100% 충족하여, `3D modeling\CarrierBoard_BeetleC6_EdgeUSB_50x50` PCB($50.0 \times 50.0\,\text{mm}$)와 하단 리튬이온/리튬폴리머 배터리를 유격 없이 견고하게 수납합니다.

---

## 1. 하우징 외형 및 내부 기구 설계 사양

| 항목 | 상세 사양 | 설계 의도 및 특징 |
| :--- | :--- | :--- |
| **외형 형상** | 사과(Apple) 유기적 곡면 회전체 | 실물 사과(Fuji/Gala 계통)와 유사한 크기 및 형상 구현 |
| **전체 치수** | **최대 직경 $\varnothing 87.0\,\text{mm} \times$ 높이 $80.0\,\text{mm}$** | 운송 상자/컨테이너 적재 시 실물 사과와 동일한 부피 차지 |
| **기본 벽 두께** | **$2.8 \sim 3.0\,\text{mm}$** | 낙하 충격 보호 및 진동 흡수 강성 확보 |
| **분할 방식** | **전/후면 2피스 클램쉘 (Front & Rear Shell)** | 조립성 극대화 및 3D 프린터 무서포트 평면 베드 안착 |
| **PCB 고정** | **M3 스탠드오프 4개소 ($43.0 \times 43.0\,\text{mm}$ 피치)** | 기판 나사 체결 높이 $8.0\,\text{mm}$ (후면 센서 돌출핀 간섭 0mm) |
| **배터리 수납** | **하단 일체형 배터리 크래들 ($52 \times 32 \times 10\,\text{mm}$)** | $3.7\text{V}$ 500~1200mAh 리튬 파우치 셀(103450/803048 등) 장착 |
| **체결 방식** | **단차 립/그루브(Tongue & Groove) + M3 볼트 4개소** | 외곽 코너 4개소 M3 체결로 빛/먼지 차단 및 내구성 보장 |

## 2. 주요 기능성 포트 및 인터페이스

1. **상단 USB-C 직결 포트 (Beetle ESP32-C6)**:
   - 상단 꼭지 함몰부에 Beetle C6의 Type-C 포트가 직결되도록 개방되어 있습니다.
   - 케이스를 분해하지 않고도 언제든지 C타입 케이블을 꽂아 **배터리 충전 및 펌웨어 디버깅/업로드**가 가능합니다.
2. **좌측 4mm 온습도 측정 환기구 (4mm Ventilation Hole)**:
   - SHT45 온습도 센서 모듈 바로 인근 외벽에 $\varnothing 4.0\,\text{mm}$ 원형 에어홀을 배치했습니다.
   - 저온 저장고 및 냉장 차량 내부의 공기가 센서에 직접 순환되어 지연 없는 정밀 온습도 측정이 가능합니다.
3. **우측 전원 스위치 조작구 (Power Switch Slot)**:
   - 기판의 SW1 슬라이드 스위치 위치에 맞춘 개구부로, 외부에서 손쉽게 전원을 ON/OFF 할 수 있습니다.
4. **전면 조도 센서 수광 윈도우 (Light Sensor Aperture)**:
   - BH1750 조도 센서의 수광면을 향해 테이퍼 가공된 개구부를 제공하여 컨테이너 개폐 여부를 감지합니다.
5. **탈부착식 사과 꼭지 액세서리 (Apple Stem & Leaf)**:
   - 상단 꼭지 소켓에 탈부착 가능한 사과 꼭지/잎사귀 부품을 제공합니다.
   - USB 케이블을 연결하지 않을 때 먼지 방지 마개(Dust Plug) 및 실물 사과 질감 연출용으로 사용됩니다.

## 3. 3D 프린팅 권장 설정 가이드 (FDM / SLA)

| 슬라이서 파라미터 | 권장 설정값 | 비고 |
| :--- | :--- | :--- |
| **노즐 구경** | 0.4 mm | 표준 노즐 권장 |
| **레이어 높이** | 0.16 mm ~ 0.20 mm | 곡면 품질을 위해 0.16mm 권장 (적응형 레이어 활용 가능) |
| **벽 라인 수 (Perimeters)** | 3 ~ 4 라인 (1.2 ~ 1.6mm) | 충격 흡수 및 나사 체결 강도 확보 |
| **상/하단 레이어** | 각 5 레이어 이상 | 돔 상부 밀폐성 유지 |
| **내부 채움 (Infill)** | 20% ~ 30% (Gyroid 권장) | 균일한 강도 및 사과 내부 완충 효과 |
| **서포트 (Support)** | 최소 트리 서포트 (Tree Support) | 배드 안착면(분할면)은 서포트 없이 출력 가능 |
| **빌드 플레이트 안착** | 브림 (Brim 5mm) 권장 | 돔 형상 출력 중 베드 탈락 방지 |
| **추천 필라멘트** | 하우징: Red PLA 또는 PETG<br>꼭지: Brown/Green PLA | 냉장 환경($0\sim 5^\circ\text{C}$) 사용 시 PETG 권장 |

## 4. 조립 순서 (Assembly Process)

```
[1단계: 배터리 수납]
  └─ 리튬이온 파우치 배터리를 후면 쉘(Rear Shell) 하단 크래들에 안착
  └─ 배터리 케이블을 우측 전용 유도로를 통해 기판 상단 방향으로 인출

[2단계: PCB 기판 체결]
  └─ CarrierBoard 50x50 기판을 4개의 M3 스탠드오프에 정렬
  └─ M3 x 6mm 둥근머리 볼트 4개로 기판을 후면 쉘에 견고하게 고정

[3단계: 케이블 연결 및 전원 확인]
  └─ 배터리 JST-PH 2.0 단자를 기판에 연결하고 SW1 전원 켜짐 확인

[4단계: 전면 하우징 결합]
  └─ 전면 쉘(Front Shell)의 돌출 단차 립(Tongue)을 후면 쉘 그루브에 맞물림
  └─ 외곽 4개소의 M3 홀에 M3 x 14~16mm 볼트를 체결하여 상/하판 고정

[5단계: 사과 꼭지 결합]
  └─ 상단 꼭지 홀에 사과 꼭지(Stem) 부품을 가볍게 삽입하여 조립 완성
```
