# Apple Digital Twin Sensor Pod v24 — SHT45 좌·우 맞통풍(Cross-Flow) & M4/M3×20mm 육각 렌치 볼트 에디션

본 폴더(`v24_Apple_Sensor_Pod_CrossFlow_HexBolt`)는 `v23`의 액티브 팬 홀더를 제거하고, **`SHT45` 온습도 센서 기준 좌·우 맞통풍구(Cross-Flow Wind Tunnel)**와 **외곽 4개소 `20 mm` 육각 렌치 볼트(DIN 912) 체결 구조**, 그리고 실제 `CarrierBoard_BeetleC6_EdgeUSB_50x50` 양면 실장 부품 6종의 **간섭 0% 최적화**를 모두 반영한 CadQuery 2.8+ B-Rep 마스터 버전입니다.

---

## 1. v23 대비 핵심 개선 사항

1. **2510 냉각팬 홀더 완전 제거**: 내부 공간을 넓히고 구조·조립을 단순화했습니다.
2. **`SHT45` 기준 좌(`-X`)·우(`+X`) 4단 맞통풍구 (Cross-Flow Wind Tunnel)**:
   * `SHT45` 온습도 센서 영역(`Z = -15.3 ~ +2.5 mm`, `Y = -12.6 ~ -1.6 mm`, 후면 배터리 앞쪽 공간)의 **양옆 좌·우 측벽(`-X`, `+X`)에 4단 대칭 통풍 슬릿(`Z = -12.5, -8.5, -4.5, -0.5 mm`, `Y = -11.0 ~ -2.5 mm`)**을 배치했습니다.
   * GPS 안테나 홀더는 전면 쉘(`Y > 0`)에, 볼트 보스 4개는 상·하단(`Z = +25 / -22 mm`)에 분리 배치하여 **좌측 구멍 → `SHT45` 센서 직격 → 우측 구멍**으로 막힘없는 직선 기류 통로를 형성합니다.
   * 상단 배기 루버(`Z = +15 ~ +50 mm`)와 하단 흡기 루버(`Z = -48 ~ -15 mm`)도 사과 외벽(`Z = -44.56 ~ +47.31 mm`)을 100% 관통하도록 수정했습니다.
3. **4개소 외곽 `20 mm` 육각 렌치 볼트(DIN 912) 체결 (`M4×20mm` 기본 / `M3×20mm` 옵션 동시 제공)**:
   * 후면 쉘 바깥쪽에서 볼트를 삽입하여 `Y = -10.0 mm` 평면 좌면(Seat)에 안착하고, 후면 통과(`10 mm`) + 전면 셀프태핑 체결(`10 mm`, 파일럿 홀 깊이 `12.5 mm`)로 **`20 mm` 볼트가 정확히 체결**됩니다.
   * 볼트 머리는 후면 쉘 카운터보어 내부에 매립되며, **전면 사과 겉면에는 구멍이 0개**입니다.
   * 4개의 강철 볼트가 분할면(`Y = 0`)을 관통해 전단 정렬 핀 역할을 겸합니다.
4. **실제 `CarrierBoard_BeetleC6_EdgeUSB_50x50` 전 부품 간섭 0% 해결**:
   * **전면 M3 스탠드오프 슬림화**: 기둥 반경을 `r = 4.0 mm` → **`r = 3.00 mm` (`Ø6.0 mm`)**로 최적화하고 외벽 보강 리브를 PCB 바깥쪽(`±Z`)으로만 연장하여 `BH1750` 및 `SHT45`(M3 홀 중심에서 `3.20 mm` 거리)와 **간섭 `0.000 mm³`**을 달성했습니다.
   * **배터리 바닥 심화 (`Y = -26.0 mm`)**: `5000mAh` 배터리(`PL105568`, `55 × 68 × 10 mm`) + `2 mm` 벨크로 장착 시에도 PCB 뒷면(`Y = -1.6 mm`)과 **`12.4 mm` 공간**이 확보되어 `SHT45`/`GY-521`/`GPS`(`10~11 mm`)와 여유 있게 조립됩니다 (최소 외벽 두께 `2.30 mm` 유지).
5. **`BH1750` 조도 센서 전용 채광창 복원**: 전면 쉘 우측(`+X`) `Z = +8.5, +14.0 mm` 위치에 65° 무서포트 2단 채광창을 복원했습니다.

## 2. 권장 PCB 실장 방향 & 볼트 규격

### 2.1 권장 PCB 장착 방향 (방향 C — 열 분리 + 맞통풍 + 채광 최적)
* **Top 면 (`Beetle ESP32-C6`, `BH1750`, `JST-PH & SW1`)** → **노란색 전면 쉘(`+Y` 돔 내부)** 방향, **USB-C 포트가 위쪽(`+Z`)**을 향하도록 M3 나사 4개로 고정합니다.
  * 발열원인 `ESP32-C6`가 넓은 전면 돔 상부에 격리되어 열기가 상단 배기 루버로 빠져나갑니다.
  * `BH1750`이 전면 우측(`+X`) 2단 채광창을 정면으로 바라봅니다.
* **Bottom 면 (`SHT45`, `GY-521`, `ATGM336H GPS`)** → **보라색 후면 쉘(`-Y` 배터리 쪽)** 방향을 향합니다.
  * `SHT45` 온습도 센서가 후면 좌·우 4단 맞통풍 풍동 정중앙에 위치하며, PCB 자체가 `ESP32-C6` 발열 차단막 역할을 합니다.
  * `ATGM336H GPS`가 좌측(`-X`)에 위치해 전면 쉘 좌측 GPS 세라믹 안테나 포켓과 최단거리로 연결됩니다.

### 2.2 외곽 체결 육각 렌치 볼트 규격 (DIN 912 / ISO 4762, 4개 필요)

| 버전 | 권장 볼트 | 카운터보어 (`-Y`) | 후면 통과홀 | 전면 셀프태핑 홀 | 특징 및 파일 위치 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **메인 (추천)** | **`M4 × 20 mm`** (3mm 육각렌치) | `Ø8.20 mm` | `Ø4.40 mm` | `Ø3.55 × 12.5 mm` | PLA 반복 개폐 시 나사산 내구성이 우수 (루트 및 `cadquery_v24/`) |
| **옵션** | **`M3 × 20 mm`** (2.5mm 육각렌치) | `Ø6.60 mm` | `Ø3.40 mm` | `Ø2.75 × 12.5 mm` | PCB 고정 나사(M3)와 규격·렌치 통일 (`m3_20mm_option/`) |
