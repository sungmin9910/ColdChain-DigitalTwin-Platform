# Sindoh 3DWOX 2X - Apple Digital Twin Pod v21 (2-Piece Ultra-Rigid Edition) 슬라이싱 & 출력 가이드

본 문서는 사용자의 피드백을 반영하여 **중간 트레이 유동(Rattle) 문제를 100% 해결**하고, **전면 쉘 직결 2피스(Front + Rear) 구조로 완성한 v21 공식 생산 매뉴얼**입니다.

---

## 1. v21 주요 혁신 및 설계 변경점 (v20 대비)

1. **부품 수 축소 (3피스 ➔ 2피스 일체형)**:
   * 덜렁거리던 분리형 배터리 트레이(`battery_tray.stl`)를 완전히 제거했습니다.
   * 메인보드(CarrierBoard)가 **전면 쉘 내부 4개 나사 기둥(43×43mm M3)에 볼트 4개로 직결 체결**됩니다.
2. **100% 진동 및 흔들림 방지**:
   * 차량 주행 진동 중에도 보드가 단 0.1mm도 흔들리지 않습니다.
   * 조도 센서(BH1750)가 전면 쉘 투광 윈도우와 **정확히 밀착 정렬**됩니다.
3. **완벽한 사과 외관 (전면 무나사 클린 디자인)**:
   * 나사는 보드 뒤쪽에서 전면 쉘 안쪽 기둥으로 조이는 **내부 체결 방식**입니다.
   * 사과 전면 돔 외관에는 나사 구멍이 전혀 노출되지 않아 고급스러운 애플 감성을 유지합니다.
4. **FDM 3D 프린터 서포트 제로화 (Anti-Overhang)**:
   * 내부 4개 기둥이 베드 접촉면($Y=0$)부터 45° 리브로 일체화되어, **전면 쉘 내부 서포트 0%로 완벽 출력**됩니다.
5. **후면 쉘 배터리 이탈 방지 리텐션 립**:
   * 5000mAh 배터리가 앞뒤로 흔들리지 않도록 좌우 고정 립과 손가락 탈착 홈(Finger Pull)이 일체형으로 탑재되었습니다.

## 3. 신도리코 3DWOX Desktop 슬라이서 추천 설정

* **노즐 직경**: 0.4 mm (PLA)
* **레이어 높이**: 0.20 mm (기본) ~ 0.16 mm (정밀)
* **벽 두께 / 루프 수**: 3회 (1.2 mm)
* **인필 (Infill)**: 18% ~ 20% (Gyroid 권장)
* **서포트 설정**:
  * 생성 위치: `모든 곳` (후면 쉘 출력 시 배터리 선반 하단 지지용)
  * 서포트 구조: `선형 구조 (Lines)`
  * 서포트 각도: `60°` (외벽에는 서포트 생성 안 됨)
  * 인터페이스 레이어: 3층 (Easy-Peel 툭 치면 분리)
* **베드 부착 (Adhesion)**:
  * 브림(Brim): 3.0 mm ~ 4.0 mm

## 4. 완벽 조립 순서 (Assembly Guide)

1. **전면 쉘에 보드 체결**:
   * CarrierBoard(센서 및 Beetle C6 실장 완료 상태)를 전면 쉘 안쪽 4개 기둥 위에 올립니다.
   * 보드 뒷면에서 **M3 볼트 (길이 6mm 또는 8mm) 4개**를 조여 단단히 고정합니다.
2. **후면 쉘에 배터리 안착**:
   * JRF PL105568 5000mAh 리튬폴리머 배터리를 후면 쉘 배터리 포켓에 밀어 넣습니다.
   * 좌우 리텐션 립 사이에 배터리가 단단히 고정됩니다.
   * 배터리 전원선을 상단 좌측 배선 홈으로 통과시킵니다.
3. **전원선 연결 및 하우징 닫기**:
   * 배터리 커넥터를 메인보드 전원 소켓에 연결합니다.
   * 전면 쉘과 후면 쉘 테두리(Rim)를 서로 맞춥니다.
4. **외곽 나사 4개 체결**:
   * 전면 쉘 외곽 4개 홈을 통해 **M3 둥근머리 볼트(길이 35mm~40mm) 4개**를 넣고 조여 하우징을 최종 마감합니다.
5. **사과 꼭지(Stem) 장착**:
   * 상단 USB-C 포트 옆 꼭지 소켓에 꼭지를 가볍게 꽂아 완성합니다.
